ImageEditor — приложение для обработки изображений

Описание

Настольное приложение на C# и WPF для загрузки, предварительного просмотра и обработки изображений.

Структура решения

\- ImageEditor — WPF-пользовательский интерфейс.

\- ImageProcessor — библиотека обработки изображений; основная операция реализована в ImageService.ProcessImage.

\- ImageProcessor.Tests — автоматизированные тесты NUnit для библиотеки обработки изображений.

Возможности обработки

\- повышение резкости изображения;

\- обнаружение контуров;

\- изменение размера;

\- сохранение обработанного изображения.

Технологии

\- C#

\- .NET 8

\- WPF и XAML

\- ImageSharp

\- NUnit

\- Visual Studio

Запуск

1\. Откройте файл решения ImageEditorSolution.sln в Visual Studio.

2\. Восстановите NuGet-зависимости, если это потребуется.

3\. Выберите проект ImageEditor в качестве запускаемого проекта.

4\. Запустите приложение.

Тестирование

Откройте Test Explorer в Visual Studio и запустите тесты проекта ImageProcessor.Tests.



Тесты проверяют обработку изображения без фильтров, изменение размеров, сохранение результата при повышении резкости и обнаружении контуров, а также обработку отсутствующего исходного файла.

Основной сценарий

Пользователь выбирает изображение, задаёт необходимые параметры обработки, просматривает результат и сохраняет его в файл.
